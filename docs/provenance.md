# Source provenance

Telesera is a new implementation by Ennio Cuteri. Its Rust engine and web interface are written in this repository from a functional specification, without copying or translating the previous application's source, assets or documentation. This repository starts with its own Git history.

The application uses independently licensed third-party libraries, notably grammers for the Telegram protocol. Those libraries retain their copyright notices and licenses. Application authorship does not claim authorship of those libraries or of the Telegram service.

The Telesera icon is an original geometric design. Screenshots intended for public documentation use fictional conversations. Private accounts, session files, API credentials and local network configuration must never be committed.
